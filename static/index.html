How Other AIs Connect in Python

External Python AIs (LangChain, CrewAI, AutoGen, scripts) can import our client: 

from client import MT5Client

# Connect to this bridge
ai = MT5Client("http://127.0.0.1:8000")

# Fetch live market data
quote = ai.get_quote("XAUUSD")
print(f"Gold Bid: {quote['bid']}, Ask: {quote['ask']}")

# Execute trade
order = ai.buy("XAUUSD", volume=0.01, stop_loss=4100.0, take_profit=4150.0)
print("Order Placed:", order)
